# Third-party references

The playbooks in this repository are an original integration written for this project. They do not vendor upstream source code, scripts, fonts, images, or other assets.

The following public MIT-licensed repositories informed the general workflows and are credited here:

- [nateherkai/scroll-craft](https://github.com/nateherkai/scroll-craft) — scroll-story planning, layered composition, and responsive motion.
- [oil-oil/oil-ui](https://github.com/oil-oil/oil-ui) — visual direction, hierarchy-first design, and screenshot-based review.
- [superdesigndev/superdesign-skill](https://github.com/superdesigndev/superdesign-skill) — optional design-canvas exploration and design-system workflows.

License declarations were checked in the upstream repositories. No upstream code or assets are included here; if code or assets are added later, verify their current license, preserve required notices, and check individual asset terms separately.

The upstream Superdesign instructions use an unpinned `npx` package command. This integration intentionally does not copy or automatically run that command. Any future tool installation or hosted-service use requires user approval and a reviewed, pinned package version.
